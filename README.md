# BridgeLabz Training - 3Y Program

A structured repository for the BridgeLabz 3-year training program covering frontend technologies: HTML, CSS, and Bootstrap.

## Branches

- **html-practice** - HTML practice and assignments
- **css-practice** - CSS practice and assignments  
- **bootstrap-practice** - Bootstrap practice and assignments
- **revision-problems** - Revision exercises and challenges
- **reviews** - Weekly reviews and progress tracking

## Folder Structure

```
├── html-practice/
├── css-practice/
├── bootstrap-practice/
├── revision-problems/
└── reviews/
```

Each folder contains:
- `gcr-codebase/` - Guided Coding Resources
- `practice-codebase/` - Personal practice work

## Get Started

Switch to your working branch:
```bash
git checkout html-practice
git checkout css-practice
git checkout bootstrap-practice
```

Add your work and push:
```bash
git add .
git commit -m "[KARAN] Add: Your description"
git push origin <branch-name>
```
